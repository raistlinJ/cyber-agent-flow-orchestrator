Hints and solutions

Uses rendered participant-guide hints, authored task hints, or discoverable facts. The hint interval must be smaller than Maximum agent turns. Tasks without usable guidance run unassisted and report that hints were unavailable.

Enabled by default; you can turn it off for this experiment. Intermediate hints are released after the selected number of turns without observed progress or after an incorrect final answer. At the configured maximum tries, provide the current challenge’s facilitator walkthrough and exact answer/flag. A try is an agent turn without new observed progress; new progress resets the count. Other challenge answers remain withheld. Both run configurations use the same policy, with up to three ordinary hints per trial and one solution per challenge. Results separate unassisted, hint-assisted and solution-assisted success.

Default: 6 agent turns without new progress. Applies only when progressive hints are enabled. The solution includes the walkthrough and answer for the first unsolved challenge. After the solution and a further hint interval plus the configured try limit without completion, that challenge is deferred and assistance moves to an independent unfinished challenge. Deferred steps remain unverified and do not unlock prerequisites. The trial still stops at its turn or active time limit.
