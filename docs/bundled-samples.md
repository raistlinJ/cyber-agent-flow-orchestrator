# Bundled ScenarioForge Samples

Both new sample presets deploy their fixed ScenarioForge XML on CORE, check readiness, export evaluation tasks, and run Cyber-agent-flow.

See the [demo profile](demo-profile.md) for current tasks, prompts, tool conditions and metrics, and [scenario experiments](scenario-experiments.md) for setup and configuration.

Older workflow illustrations depict the historical participant-only samples and are not the current execution path.

Sample presets include evidence rubrics and use Exact checks by default, switching to Both when Judge LLM is enabled. The [five importable bundles](../ScenarioForge-Bundles/README.md) use Both by default and include task, rubric, JSON profile and Markdown summary files.
